# SimpleWordle
Tugas Proyek 1 Berpikir Komputasional WI1102

Halo! ini adalah tugas projek 1 dari kelompok 3 dengan nama "Pecinta Verity" dengan mengambil judul yaitu "Sistem Wordle dengan Solver dan Leaderboard". Dalam file .zip akan ditemukan dua file .py utama, yaitu wordle.py (utama) dan leaderboard_gui.py (sampingan). Untuk memulai program, jalankan file wordle.py. Untuk file leaderboard_gui.py, kodenya sudah masuk dalam file pertama, dengan menggunakan panggilan fungsi "tampilkan_gui_leaderboard()"
